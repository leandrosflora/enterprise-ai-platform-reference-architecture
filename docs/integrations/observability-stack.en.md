# Observability Stack Integration

## Objective

Integrate the platform with corporate observability tools for operation, audit and diagnosis.

## Standards

- OpenTelemetry
- Structured Logs
- Metrics
- Distributed Tracing
- Dashboards
- Alerts

## Compatible tools

- Grafana
- Prometheus
- Loki
- Tempo
- Dynatrace
- Datadog
- OpenSearch Dashboards

## Data collected

- Trace of invocation of agent
- Tool calls
- Model calls
- Retrieval calls
- Tokens
- Latency
- Erros
- Estimated costs

## Requirements

- Compulsory correlation
- Masking of sensitive data
- Retention by type of data
- Dashboards by platform, agent and business unit
