# Observability Stack Integration

## Objective

Integrating the platform with corporate observability tools for operation, audit and diagnosis.

## Standards

- OpenTelemetry
- Structured Logs
- Metrics
- Distributed Tracing
- Dashboards
- Alerts

## Compatible tools

- Grafana
- Prometheus
- Loki
- Tempo
- Dynatrace
- Datadog
- OpenSearch Dashboards

## Collection Data

- Trace of official invocation
- Tool calls
- Model calls
- Retrieval calls
- Tokens
- Latency
- Erros
- Estimated costs

## Requirements

- Compulsory CorrelationId
- Sensitive data masking
- Retention by type of data
- Dashboards per platform, agent and business unit
