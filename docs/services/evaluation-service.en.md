# Evaluation Service

## General view

The .Evaluation ServiceIt assesses the quality of the responses generated by agents: groundedness, relevance, hallucination, toxicity and quality regression.Agent RuntimeWith every invocation and byGovernance Serviceduring the approval of agents.

## Responsabilidades

- Assess groundedness and relevance of responses
- Detecting hallucinations and toxicity
- Execute regression assessments for new versions of agents
- Publish the result of the governance and audit assessment for consumption
- Support for synchronous (blocking, for approval) and asynchronous (post execution, for continuous monitoring) evaluation

## Out of scope

- Execution of the agent
- Final approval decision (to Governance Service, which consumes the result of the evaluation)
- Calculation of cost

## API Principal

```http
POST /evaluations
GET /evaluations/{id}
```

## Dependencies

| Dependence | Uso |
|---|---|
| Agent Runtime | Origin of the assessed responses |
| Governance Service | Consume result for approval decision |
| Kafka | Publish and consume evaluation events |

## Events Published

- `evaluation.started`
- `evaluation.completed`

## Non-functional requirements

| Requisito | Diretriz |
|---|---|
| Latency | Asynchronous evaluation shall not block the user response |
| Consistency | Versioned and reproducible evaluation criteria |
| Auditoria | Any evaluation result is traceable to an agent invocation or version |
| Escalabilidade | Supports batch evaluation for return |
